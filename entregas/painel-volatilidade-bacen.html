⚡ Painel de Volatilidade BACEN · SGS — Risco em Tempo Real (Histórico)

O que este painel faz: consome a API oficial do Banco Central (SGS), calcula a volatilidade realizada (dispersão dos retornos) de câmbio, juros e preços, anualiza, abre janela móvel e classifica o regime (alta/estável/baixa). Use para dimensionar margem de caixa, precificação e cláusulas contratuais — não é previsão de preço. Filtre, recalcule e exporte no navegador.

Fonte: API SGS (api.bcb.gov.br) · coleta embutida no arquivo · fórmulas: retorno log, dp amostral (n-1), anualização √252/√12, janela móvel, regime vol21/vol252, drawdown. Tema azul pastel.
